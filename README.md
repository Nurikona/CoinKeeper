### CoinKeeper 
Coinkeeper - это веб-приложение для отслеживания личных финансов, позволяющее пользователям управлять доходами и расходами, анализировать финансовые привычки и контролировать бюджет.

## ✨ Функциональные возможности

### Аутентификация

* Регистрация новых пользователей
* Вход в систему с использованием email и пароля
* Выход из системы

### Управление транзакциями

* Добавление новых транзакций (доходы и расходы)
* Редактирование существующих транзакций
* Удаление транзакций
* Фильтрация транзакций

### Категории

* Создание пользовательских категорий
* Настройка иконок и цветов для категорий
* Удаление категорий

### Статистика и аналитика

* Визуализация доходов и расходов по категориям (круговые диаграммы)
* Сравнение доходов и расходов по месяцам (столбчатые диаграммы)
* Фильтрация статистики по дате

### Дашборд

* Отображение текущего баланса
* Список последних транзакций
* Быстрый доступ к добавлению новых транзакций

## 🛠️ Технологии

* **Frontend**: React.js, TypeScript
* **Маршрутизация**: React Router DOM
* **Управление состоянием**: Redux Toolkit
* **Стилизация**: TailwindCSS, shadcn/ui
* **Графики и диаграммы**: Recharts
* **Формы и валидация**: React Hook Form (опционально)
* **Иконки**: Lucide React
* **Форматирование дат**: date-fns
* **Уникальные идентификаторы**: uuid

## 🚀 Установка и запуск

### Предварительные требования

* Node.js (версия 16.x или выше)
* npm или yarn

### Шаги по установке

1. Клонировать репозиторий:

```shellscript
git clone https://github.com/yourusername/coinkeeper.git
cd coinkeeper
```

2. Установить зависимости:

```shellscript
npm install
# или
yarn install
```

3. Запустить приложение в режиме разработки:

```shellscript
npm run dev
# или
yarn dev
```

4. Открыть [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшена

```shellscript
npm run build
# или
yarn build
```

## 🔌 API

В текущей версии приложение использует моковые данные для демонстрации функциональности. В реальном проекте следует заменить моковые данные на взаимодействие с реальным API.

### Моковые эндпоинты:

* **Аутентификация**:

* `POST /api/auth/register` - Регистрация нового пользователя

* `POST /api/auth/login` - Вход в систему

* `POST /api/auth/logout` - Выход из системы

* **Транзакции**:

* `GET /api/transactions` - Получение списка транзакций

* `POST /api/transactions` - Создание новой транзакции

* `PUT /api/transactions/:id` - Обновление транзакции

* `DELETE /api/transactions/:id` - Удаление транзакции

* **Категории**:

* `GET /api/categories` - Получение списка категорий

* `POST /api/categories` - Создание новой категории

* `PUT /api/categories/:id` - Обновление категории

* `DELETE /api/categories/:id` - Удаление категории
